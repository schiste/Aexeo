Write a useful team handover

A handover helps another person take the next step without reconstructing the entire project. Start with the current situation and link to the records that contain the details.

Describe the state

Summarize what is complete, what remains open, and which decisions need attention. Mark assumptions clearly so the next person knows what to verify. If an event has a deadline, include the date and explain who agreed to it.

Make actions easy to find

List each next action with an owner and an expected result. If nobody has accepted ownership, leave it open and say how the team will decide. Keep decisions separate from proposals so a reader does not mistake an idea for an approved plan.

Check the note with a reader

Ask someone who has not been involved to identify the first action and the person responsible. Use their questions to add missing context or remove detail that obscures the next step. Keep sensitive information in its designated location instead of copying it into the handover.
