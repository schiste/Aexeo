# A practical handover note for a small team

A handover records context. It helps the next person decide without reconstructing past conversations. Use it for leave, ownership changes, or support across shifts.

## Start with the decision in front of the reader

Name the task and its status. Explain the next decision. For example, a release may need a final check, or a supplier may owe a date. Date the note so the reader can judge how current it is.

## Separate facts from questions

List what has been confirmed and link to the relevant record where the reader can access it. Put unresolved questions in a separate section, with the person responsible for each one. If nobody owns a question yet, say so rather than assigning it by guesswork.

## Make the next action easy to find

End with a short list of actions in the order they need attention. For each action, identify an owner and any deadline that has actually been agreed. If there is no deadline, leave it open. Finally, ask the recipient to confirm that they can access the linked materials and know who to contact for context.
